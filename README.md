# EaseUI 🚀

EaseUI is a modern, lightweight UI component library built using **React**, **TypeScript**, and **Tailwind CSS**. It provides reusable, fully customizable UI components along with interactive documentation pages.

## Features 🌟
* **Button:** Highly customizable buttons with variants, sizes, and animations.
* **Modal:** Clean and accessible popup dialog boxes.
* **Tooltip:** Hover-based information popups supporting multiple positions (Top, Bottom, Left, Right).
* **Carousel:** Smooth slideshow component with autoplay and navigation controls.
* **Layout:** Structural wrappers for headers, sidebars, and dashboards.

## Tech Stack 🛠️
* React
* TypeScript
* Tailwind CSS
* Vite
